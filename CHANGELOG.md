## [0.1.0] - 2026-07-26

### Added

- Safe Rust tessellation for open and closed wide polylines.
- Adaptive chained quadratic and smooth cubic Bezier flattening.
- Deterministic Poisson-disk streamline seed generation.
- Optional annotations, total spine lengths, random offsets, and curve guides.
- Triangle-list and triangle-outline index output.
- Tests, examples, CI, crates.io publishing, and tag-driven GitHub releases.
